Authentication API Reference

Welcome to the WebRAG Studio authentication docs. This reference explains how to issue, refresh, and revoke bearer tokens for API requests.

Important: Never expose client secrets or API keys in frontend code or public repositories. Store secrets securely on your backend service.

Token Generation

To acquire an access token, send a POST request to the /oauth/token endpoint with valid client credentials.

curl -X POST https://api.webrag.local/v1/oauth/token \
  -H "Content-Type: application/json" \
  -d '{"client_id": "demo_app", "grant_type": "client_credentials"}'

Supported Scopes

The following OAuth scopes are available for access tokens:

  • read:blocks - Allows extracting semantic page blocks.
  • write:chunks - Permits chunking and vector storage operations.
  • execute:rag - Grants access to local similarity retrieval and LLM answer generation.

Response Format

Field Type Description
access_token string JSON Web Token (JWT) used to authenticate API requests.
expires_in integer Token validity duration in seconds (default 3600).
token_type string Always Bearer.
